# vulplatform
A module for vulpin for detecting platform name.


# Usage:
```basic
U"platform"
Gplatform.detect()
```
Output:
```
U"platform"
G"You are using:"
Gplatform.detect()
```


And another example!
```
U"platform"

?platform.detect()=="linux"
    G"You are happiest linux user!"
:
G"You are not using linux :("
;
```
